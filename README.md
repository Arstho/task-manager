Task Manager 📋
Приложение для управления задачами, построенное на современном стеке технологий React/Next.js.

🚀 Технологии
Next.js 15.5.3 - React фреймворк с App Router
React 19.1.0 - Последняя версия React
TypeScript - Статическая типизация
Redux Toolkit 2.9.0 - Управление состоянием
React Hook Form + Zod - Формы с валидацией
SCSS Modules - Стилизация с модулями
React Redux 9.2.0 - React биндинги для Redux

✨ Возможности:
✅ Добавление, редактирование и удаление задач
🎯 Приоритеты задач (высокий, средний, низкий)
🔍 Поиск и фильтрация задач
📊 Статистика продуктивности
🌙 Темная/светлая тема
💾 Локальное сохранение данных
📱 Адаптивный дизайн

📝 Скрипты:
npm run dev - Запуск development сервера
npm run build - Сборка production версии
npm run start - Запуск production сервера
npm run lint - Проверка кода с ESLint
